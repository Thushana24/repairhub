# RepairHub: Facility Maintenance Management System

Tenants raise repair requests, supervisors assign technicians,
technicians complete jobs, and admins monitor performance.

**Live demo:** (coming soon) | **API docs:** (coming soon)

## Features

- **Tenant:** create repair requests with photos, track status, comment, rate completed jobs
- **Supervisor:** view and filter all requests, assign and reassign technicians
- **Technician:** view assigned jobs, update status with notes
- **Admin:** manage users, buildings and units, view dashboard reports

## Tech stack

React, TypeScript, Tailwind CSS, React Hook Form, Zod, Zustand, TanStack Query,
Node.js, Express, Prisma, PostgreSQL
